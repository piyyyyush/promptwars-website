# Multi-Agent AI Interview Panel Simulator

A polished Streamlit frontend prototype based on the provided problem statement.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What this version does

- Upload Job Description, Resume, and Interview Transcript
- Shows an AI-style processing screen
- Builds a demo candidate profile
- Displays 4 independent agent cards
- Shows evidence-backed agent opinions
- Includes a debate timeline with an opinion change
- Produces a final recommendation without simply averaging scores

This is a frontend/demo foundation. The files are intentionally structured so real LLM calls can later replace the demo analysis functions.
